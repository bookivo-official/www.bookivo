EMAIL SETUP STILL REQUIRED
1. Supabase > Authentication > Emails > Templates. Paste docs/email-otp-template.html into BOTH Confirm signup and Magic link or OTP. Subject: Your BOOKIVO verification code. Save each template. Keep {{ .Token }} intact; do not place it inside an href.
2. Authentication > Sign In / Providers > Email: set Email OTP length to 6. Keep email confirmation enabled. Request a fresh code after saving; older emails do not change.
3. Guest checkout uses a separate four-digit code implemented by bookivo-store. It requires RESEND_API_KEY and BOOKIVO_FROM_EMAIL in Edge Functions > Secrets. Use a sender on a verified domain in Resend. Supabase Auth SMTP settings do not automatically provide those credentials to the Edge Function. Do not put keys in frontend files or GitHub.
4. Verify with a new email signup, existing email login, and guest checkout. Confirm receipt, wrong-code rejection, expiry, successful verification and payment access. These real email delivery checks were not completed in this update because dashboard control was blocked.
