# Bookivo block style

When Sam asks to make a block “like our Bookivo other blocks,” use the shared classes:

- `.bookivo-block` for a white, rounded surface with a light border and soft blue-gray shadow.
- `.btn.btn-shine` for the Bookivo blue gradient button with a moving light sweep, lift and shadow.

Use these on new modal, form, and content blocks so the site keeps the same visual language. Keep the block responsive and preserve the existing IDs and `data-*` hooks used by its JavaScript.
